# R21 · AI readiness report

## Goal

On demand, for any folder, show how ready it is for coding agents: rule results from a local scan, a model review of the gaps and of the AI files the user ticks, and advice the user can turn into a change request or the baseline plan.

## Scenarios that prove it

- `features/ai-readiness.feature` (all scenarios).
- Unit tests: each rule in `rules.test.ts` against the fixture folders; `grounding.test.ts` (paths and lines outside the scan are dropped; ratings never raised); `secrets.test.ts` (patterns match, values never leave `findSecrets`).

## Data

- `ReadinessRule`: `{ id, area, applies(scan), check(scan, readLocal) => { status: 'pass' | 'fail' | 'na', evidence: Evidence[], params? }, advice: { title, why, impact, effort, action } }`.
- `Evidence`: `{ path: string; line?: number }`. Paths are relative to the folder root.
- Model answer per area (zod schema, rejected and retried once when invalid):
  ```json
  {
    "why": [{ "rule": "AI-03", "text": "..." }],
    "findings": [{ "summary": "...", "evidence": [{ "path": "AGENTS.md", "line": 41 }], "lowersRating": true }],
    "advice": [{ "title": "...", "why": "...", "evidence": [{ "path": "..." }], "impact": "High", "effort": "Small", "action": "add" }]
  }
  ```
  At most 3 findings and 3 advice items per area.
- `ReadinessReport`: `{ id, date, folderCase, model, durationMs, read: string[], areas: { area, rating, summary, evidence, source }[], mapping?: { file, keel, proposal, note }[], advice: { id, title, why, evidence, impact, effort, source, rule?, action }[], modelError? }`. `read` holds names only.
- Advice IDs are stable across runs: the rule ID for rule advice, a hash of area, title and evidence paths for model advice. Ignored IDs are read from the latest report and hidden.

- `src/components/` nav: "AI readiness" in the project group and in the "This folder" group.
- `src/app/(keel)/initialise/…` (or where R15 put Initialise): the optional card in What Keel found; preselect from accepted advice; baseline plan section "From the readiness report".
- `src/lib/settings/settings.ts` and the Settings page: "Readiness report" template select.
