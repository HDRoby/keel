# R8 · Optional push to the existing remote

## Goal

Replace the GitHub push (T8b) with an optional `git push` to the folder's existing remote.

## Scenarios that prove it

- `features/handoff.feature` › Pushing uses the folder's own remote

## Files that are likely to change

- `src/lib/github/push.ts`: remove repository creation, `handoffDir` and the token in the push URL. Keep `cleanError`.
- New `src/lib/store/remote.ts`: `remoteOf(root)` from `git remote get-url origin`; `push(root)` runs `git push origin HEAD` with the user's own git credentials and environment.
- `src/lib/github/auth.ts`: token only for optional CI results (R6), read from the user settings.
- Handoff page: the Push button shows only when there is a remote: "Push to origin (github.com/owner/repo)". Without a remote: "No remote. Push from your terminal when you are ready."

## Notes

- Never push automatically.
