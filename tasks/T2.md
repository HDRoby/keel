# T2 · Template engine and template library

## Goal

Load templates from seed/templates on first run, let the user edit them as new versions, and render documents from them.

## Scenarios that prove it

- `features/templates.feature` › A template used by a project cannot be removed (@REQ-003)

## Files that are likely to change

- `src/lib/templates/library.ts`
- `src/lib/templates/render.ts`
- `src/app/templates/page.tsx`

## Notes

- Templates are grouped by kind (intent, spec, plan, roadmap, decision, agent instructions, agent kit).
- Placeholders use double braces, for example {{project_id}}.
- Removal is blocked while any project uses the template; show which projects.
- As built: the library lives in `KEEL_HOME/templates/`, one immutable file per version (`<id>@<version>.md`). It is copied from `seed/templates` and `seed/agent-kit` when that folder does not exist yet. Saving an edit writes the next version; older versions stay. Removal deletes every version and is refused (in the UI and in `removeTemplate`) while any project document references any version. Usage is read from the project files, not the index. Pages: `/templates` and `/templates/[id]`; form actions in `src/app/templates/actions.ts`.
- Seed kinds `task` and `change` are shown under Plan and Decision records.
