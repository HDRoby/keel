Intent: Keel

Problem

Coding agents now build software in hours, but the steps before the build still run at human speed. Ideas wait for someone to write them up, and requirements and design pass through meetings and handoffs before an engineer can plan.

Desired outcome

A web app where anyone with an idea brainstorms with an LLM, then produces a versioned intent, spec and plan with metadata and traceable requirements. It hands a scaffolded repository to any coding agent (Claude Code, Codex and others) and reads changes back.

{{r.id}} {{r.text}}

Who it is for

Proposers (engineers, product managers, anyone with an idea), coding agents, git hosting (GitHub first), LLM providers.

Constraints

Web UI, not a VS Code extension. Not tied to one model or agent. Single user first. Stops at plan and scaffold: no code generation.
