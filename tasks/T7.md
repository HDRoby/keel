# T7 · Version diff, impact view and mock references

## Goal

Show version history with diffs and reasons, the impact of a version by requirement, and attach mock references linked to requirements.

## Scenarios that prove it

- `features/versions.feature` › Comparing two versions shows what changed and why (@REQ-008)
- `features/mock-references.feature` › A mock reference is linked to requirements (@REQ-010)

## Files that are likely to change

- `src/lib/versions/diff.ts`
- `src/lib/versions/impact.ts`
- `src/lib/mocks/references.ts`
- `src/app/projects/[id]/plan/page.tsx`

## Notes

- Every version records a reason.
- Mock references: links, PNG, JPG, PDF or HTML up to 10 MB, saved under docs/mocks/. No mock generation.
- As built:
  - Version history (`/projects/[id]/versions?doc=<path>&v=<n>`) is read from git through Keel's commit messages, so it matches the repository.
    - It lists every version with its date and recorded reason. Approvals keep the version number, so they do not appear as versions.
    - Selecting a version shows the line changes from the version before (added and removed lines, a little context, the rest folded) and the reason.
    - It also shows the impact by requirement ID: requirements whose statement changed or that sit on a changed line, plus the tasks and scenarios linked to them (`src/lib/versions/impact.ts`, built on the T5 trace).
    - Every stage document links to its history ("Version history").
  - Mock references (`src/lib/mocks/references.ts`) are attached on the Intent and Spec stages: a link (http or https only) or a file.
    - Files are recognised by content, not by name: PNG, JPG, PDF, or HTML without binary bytes. They are limited to 10 MB, checked in the browser and again on the server; the server action body limit is raised to 11 MB in `next.config.mjs`.
    - Files are saved as `docs/mocks/mock-NNN-<name>.<ext>`.
    - `docs/mocks/README.md` holds the list: the references in front matter for Keel, and a table for people (the same layout as Keel's own docs/mocks/README.md).
    - Each reference can be linked to the project's REQ IDs; unknown IDs are refused.
    - Uploaded files are not shown inside Keel; HTML in particular is never rendered.
    - The traceability page has a Mocks column.

## Questions for the owner

Answered by the owner on 2026-11-20:

1. Previews: images get a thumbnail. Done: PNG and JPG references show a thumbnail, served by `GET /api/projects/[id]/mocks/[mock]`. It serves only files that are still images by content, with `nosniff` and `default-src 'none'`. PDF and HTML are listed, never rendered.
2. Removing and replacing: both. Done: Replace swaps the link or file but keeps the MOCK ID, document and linked requirements, and removes the old file in the same commit. Remove deletes the reference and its file. Git keeps the history, and IDs are never reused (`next_mock` in docs/mocks/README.md).
