# Seed library

Loaded into Keel on first run and versioned from there (REQ-003, REQ-011).

- `templates/` document templates: intent (standard, light), spec (standard, short), plan, task, roadmap, decision record, change request, AGENTS.md, REVIEW.md
- `styles/` brainstorm styles as skill files
- `agent-kit/` subagent templates with placeholders filled per project
- `standards/` example standards (company, personal, project)

Placeholders use double braces, for example `{{plan_path}}`.
